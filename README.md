# Grapple Ghost

A 2D precision platformer where you swing, dash, and race your own ghost.

> 🚧 **Status:** In development — Week 1 of 4

![Gameplay GIF](docs/gameplay.gif)

## About

Grapple Ghost is a small, fast-paced 2D platformer built in **Godot 4**.
You move through short levels using a grappling hook, a dash, and a jump.
Your best run is replayed as a translucent ghost so you can race yourself.

This is my first Godot project, built to learn 2D game development and
to have a finished, playable game in my portfolio.

## Controls

| Action | Key |
|---|---|
| Move | A / D or ← / → |
| Jump | Space |
| Dash | Shift |
| Grapple | Right Mouse Button |
| Restart level | R |
